# Аудио каталога

Первый файл Project_36.mp3 загружен в существующий проект Supabase: Storage → catalog-audio → SUPERSTAR. Бакет публичный, MP3 предназначены для воспроизведения посетителями сайта. Серверный ключ в браузер не передаётся. В Git нет аудиофайлов.

## Добавить следующий трек

1. Выполните из папки проекта `node scripts/upload-catalog-audio.mjs RELEASE-SLUG "/absolute/path/track.mp3"`. Скрипт использует существующие SUPABASE_URL и SUPABASE_SERVICE_ROLE_KEY из локального серверного окружения. Он не перезаписывает файлы: имя включает хеш содержимого.
2. Полученную ссылку добавьте как `audioUrl` к соответствующему релизу в `components/data/catalog.ts`.
3. Можно вместо скрипта загрузить MP3 вручную через Supabase Dashboard, скопировать Public URL и указать его в том же поле. Ограничение бакета: MP3 до 20 МБ.
4. У остальных релизов звук пока не задан. Плеер показывает Audio coming soon и не проигрывает чужой трек.

## Настройки

`VINYL_CONFIG` в `components/catalog/ReleasePlayer.tsx`:

- `rpm`: обороты пластинки в минуту, сейчас 16.
- `wheelSecondsPerPixel`: чувствительность скрола над пластинкой, сейчас 0.025 секунды на пиксель.
- `secondsPerTurn`: секунд перемотки на полный ручной оборот, сейчас 10.
- `fadeSeconds`: плавное включение/выключение звука, сейчас 0.65 секунды.
- `volume`: стартовая громкость, сейчас 0.7.

Нажатие обложки запускает звук и выдвигает пластинку. Повторное нажатие убирает звук и пластинку, затем возвращает позицию трека к началу. Поворот пластинки по часовой стрелке перематывает вперёд, против часовой — назад. Во время перемотки звук приглушается. Для клавиатуры доступны стрелки, Home и End на пластинке.

Аудио не подгружается до первого нажатия. Supabase отдаёт файлы с поддержкой Range и CORS; начало и перемотка проверены на предоставленном MP3. Уход со страницы останавливает воспроизведение. При reduced motion автоматическое вращение и пространственные переходы отключены.

Скрол при наведении на видимую часть пластинки перематывает трек: вниз/вправо — вперёд, вверх/влево — назад. В этот момент прокрутка страницы перехватывается только над пластинкой. При любой перемотке сверху блока появляется таймлайн с opacity 0.7 и скрывается через секунду после завершения взаимодействия.

Пробел во время воспроизведения ставит трек на паузу, повторный пробел продолжает с той же позиции. Пластинка остаётся выдвинутой и останавливается на паузе; ручная перемотка остаётся доступной. Пробел работает и при фокусе на обложке. Ввод текста, регулятор громкости и остальные кнопки сохраняют стандартное поведение. Нажатие/Enter на обложке по-прежнему полностью останавливает трек с возвратом к началу.
